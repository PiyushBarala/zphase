# External Binaries Directory

This directory is intended for optional helper binaries used by Z Phase:
- `yt-dlp.exe`
- `ffmpeg.exe`

### Download Links:
- **yt-dlp**: [https://github.com/yt-dlp/yt-dlp/releases/latest](https://github.com/yt-dlp/yt-dlp/releases/latest) (download `yt-dlp.exe`)
- **ffmpeg**: [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/) (download `ffmpeg-release-essentials.zip` and extract `ffmpeg.exe` here)

These binaries are ignored by Git to keep the repository lightweight.
